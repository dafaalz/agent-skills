# Impeccable delta

Apply these seven checks on every frontend build and polish pass. Each check ends with a binary pass condition.

## Scope

Use this file for operate screens and persuade surfaces alike. Operate screens must pass checks 1 to 4 on every run. Persuade surfaces must pass all seven. Skip a check only with written brief approval.

## How to use

Run checks 1 to 4 during the build. Run checks 5 to 7 at finish review. Record each result as pass or FAIL with gate number. Fix FAIL before ship. Log results in the CSS stamp or review report.

## 1. Tint text on colored surfaces

Never place gray text on a colored surface. Derive secondary text from the surface hue or from the foreground token.

Pass condition. Zero gray hex or gray token on colored fills. Contrast still meets body 4.5 to 1 and large 3 to 1.

## 2. Theme browser surfaces

Theme selection, caret, scrollbar, focus ring, underline offset, and tabular numerals from the palette. Ship no browser default on crafted pages.

Pass condition. Stylesheet sets selection, focus visible, scrollbar, and numeral rules. Zero default blue outline.

## 3. Skip eyebrow on operate screens

Delete kicker or eyebrow above headings on tables, forms, dashboards, and settings. The heading carries its own weight.

Pass condition. Zero eyebrow element on operate routes. Editorial pages may keep one only with brief approval.

## 4. Run DESIGN.md drift check

Compare code tokens against project DESIGN.md and active CSS before ship. Lift one-off values into named tokens or replace them with existing tokens.

Pass condition. Zero raw hex outside token file. Zero font family outside contracted stack. Drift listed or fixed.

## 5. Keep one authored motion moment

Ship at most one authored motion moment per view. Never repeat one identical entrance on every section. Keep functional motion under 300ms.

Pass condition. Motion list names one moment plus its purpose. Reduced motion fallback present.

## 6. Isolate finish review

Run finish review in fresh context. Pass request, answers, artifact path, screenshots, direction contract, and hook findings as inputs. Inherit no transcript.

Pass condition. Reviewer input packet lists all seven inputs. Verdict recorded as Approve or Changes Requested.

## 7. Guard live iteration

Run live browser iteration only on trusted local checkout. Never inject helpers into production sites. Never weaken CSP for preview.

Pass condition. Target URL is localhost or local file. Prod URL routes to detect read only.

## Result log

Write one line per check in the review report.
Mark FAIL with file path and fix.
Close all FAIL before ship.

## Exclusions

This file ships no binary, no decision server, and no image generation. Rules here are text checks an agent runs by reading code and rendered output. For the full 58 gate sweep, use `slop-test.md` first, then apply this delta.
